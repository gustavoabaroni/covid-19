# Pulmão Limpo

App para acompanhar quem quer parar de fumar.

A pessoa informa quantos cigarros fuma por dia e há quanto tempo, e o app:

- **encaminha** para o posto de saúde (UBS) mais próximo, para o Programa Nacional de Controle do Tabagismo (INCA/SUS) e para o tratamento gratuito com adesivos, gomas e pastilhas de nicotina, que o profissional da UBS receita;
- mostra um **pulmão** que começa sujo, de acordo com a carga tabágica, e vai ficando limpo a cada dia sem fumar;
- tem um **diário** para registrar como a pessoa está se sentindo, com texto, nível de vontade de fumar e áudio;
- acompanha dias sem fumar, cigarros evitados, dinheiro economizado e as melhoras no corpo ao longo do tempo.

## Como usar

Abra `index.html` no navegador do celular. Não precisa instalar nada.

Os dados ficam salvos apenas no próprio aparelho.

> O app não substitui a consulta. Medicamentos só devem ser usados com orientação e receita de um profissional de saúde.
